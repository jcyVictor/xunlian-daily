# 循练 · 每日训练

适合新手的固定器械训练网页应用，可部署到 GitHub Pages。无需账号、构建或后端。

## 功能

- 每日进食、酸痛、精神状态和异常症状检查。
- 每天都有安排：周一肩胸维持、周三腿部、周五背部固定器械力量，其余日子低强度有氧、网球或主动恢复。
- 力量训练按 A/B/C 轮换，默认留出约 48 小时恢复；计划会根据状态检查自动暂停不合适的训练。
- 动作提示、每组重量与次数、完成打卡、按实际时间计算的组间倒计时。
- 饮食与补剂说明、中午训练时间表。
- 训练历史、体重记录、最近 7 天已记录体重的均值。
- 本机保存、JSON 备份导出与恢复。HTTPS 首次完整加载后支持离线打开。

## GitHub Pages

将本目录中的文件放到一个公开仓库根目录。

仓库 Settings → Pages → Build and deployment → Deploy from a branch → 选择 main、/(root) → Save。

部署完成后，Pages 页面会给出网址。免费 GitHub Pages 通常使用公开仓库；不要上传个人训练备份或聊天文件。

## iPhone

1. 用 Safari 打开部署后的 HTTPS 网址。
2. 分享 → 添加到主屏幕 → 添加。
3. 从主屏幕“循练”打开，完成今日状态检查。
4. 训练时按实际完成情况记录，不需要做满全部组数。

建议添加到主屏幕后再开始长期记录。Safari 标签页与主屏幕应用的存储行为会因 iOS 版本不同而有差异，换入口前先导出备份。首次离线使用前，请联网打开一次并等页面加载完成。

## 数据与限制

训练记录和体重只保存在当前设备的浏览器存储中，不会上传到 GitHub。清理网站数据、更换域名、设备或浏览器会影响记录，请定期在“记录”页导出备份到“文件”。恢复备份会替换当前记录，界面会要求确认。

没有云同步、推送或后台 AI。应用按内置规则和用户输入生成每日建议，不会自动读取聊天。手机锁屏时可能不发出计时提醒，但重新打开时会按实际经过时间校正倒计时。

计划适用于一般健身安排，不用于诊断疼痛或替代医疗评估。输入的热量和蛋白质默认值应按个人情况调整。

## 维护

入口 index.html，样式 app.css，页面交互 app.js，计划逻辑 core.js。

更新文件时同时更新 sw.js 中的 CACHE 版本。关闭所有应用窗口并重新打开后可切换新版本，训练数据仍使用原本的本机存储键。
